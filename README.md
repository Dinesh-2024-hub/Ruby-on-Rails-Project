# Twitter Clone

A Twitter-like social media web application built with Ruby on Rails.

## Features

- User registration and login
- Create posts
- View posts
- Edit posts
- Delete posts
- Timeline/feed
- Follow and unfollow users
- User profiles

## Technologies

- Ruby
- Ruby on Rails
- SQLite
- HTML / CSS
- JavaScript
- Git / GitHub

## Ruby Version

- Ruby 3.4.2
- Rails 8.1.3.1

## System Dependencies

Make sure the following are installed:

- Ruby
- Rails
- Bundler
- SQLite3
- Git
